# Portal de Objetivos en Cascada

Demo funcional del sistema corporativo de objetivos, proyectos y actividades alineado con la Evaluación de Desempeño.

## Funciones incluidas

- Vistas de Administrador, Dirección, Líder y Colaborador.
- Creación y validación SMART de objetivos estratégicos.
- Distribución de objetivos entre distintas áreas.
- Delegación de metas y actividades a equipos propios o interárea.
- Captura de avance, comentarios y evidencia.
- Propagación visual desde actividades hasta el objetivo corporativo.
- Detección de cuellos de botella y responsables.
- Configuración conceptual para precargar resultados en la EDD 2027.
- Datos de demostración persistentes en el navegador.

## Ejecutar localmente

Requiere Node.js 20 o superior.

```bash
npm install
npm run dev
```

## Subir a GitHub

1. Descomprime el ZIP.
2. Crea un repositorio nuevo.
3. Sube todos los archivos y carpetas incluidos.
4. Clona el repositorio y ejecuta los comandos anteriores.

## Alcance de la demo

La información se guarda localmente en el navegador. La versión productiva deberá conectar autenticación corporativa, base de datos, almacenamiento de evidencias y los catálogos reales de empleados, líderes, áreas y periodos.
